## About

This game was made for Jame Gam #36, where the theme was **Other World** and the required **Special Object was a Candle.** In the game the candle's flame can be toggled, and that results in changes in the environment, like doors opening. For parts of the game you have to navigate in the dark, but there are candles on the way that can be lit so it's easier to recover back to that point.
